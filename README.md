# pactómetro.es · código fuente

Rama de trabajo, no se publica (GitHub Pages publica la rama principal, que contiene la web ya construida).

- `src/pactometro.html`: la aplicación (HTML, CSS y JavaScript).
- `scripts/`: generación de los datos (`build_site_data.py` y compañía) y de la web publicable (`build_dist.py`).
- `autonomicas/`: resultados autonómicos recopilados (CSV).
- `encuesta-google-apps-script.gs`: script de la hoja de Google de la encuesta (y de la noche electoral).
- `brand/`: logotipos e iconos.
